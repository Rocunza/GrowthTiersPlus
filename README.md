# Growth Tiers Plus

**Steam Workshop:**  
https://steamcommunity.com/sharedfiles/filedetails/?id=3827770524

A RimWorld mod by **ZCN**. Adds customizable **growth tiers 9 and 10** while leaving vanilla **growth tiers 1–8 unchanged**.

**Supported versions:** RimWorld 1.6 / 1.7  
**Requirements:** Biotech DLC, Harmony  
**Save compatibility:** Can be added to existing saves.  
**Languages:** English, Korean

## Features

- Adds growth tiers 9 and 10 for children.
- Both additional tiers can be enabled or disabled individually.
- Configurable growth-point requirements (defaults: 168 / 172).
- Configurable minimum and maximum passion gains.
- Configurable passion and trait choice counts.
- Vanilla growth tiers 1–8 remain unchanged and cannot be configured by this mod.

## Installation

**Steam Workshop (Recommended)**

Subscribe to the mod on Steam Workshop and enable it in RimWorld's mod list.

**Manual Installation**

1. Install Harmony and ensure the Biotech DLC is enabled.
2. Download the latest ZIP from [GitHub Releases](https://github.com/Rocunza/GrowthTiersPlus/releases).
3. Extract the `GrowthTiersPlus` folder into your RimWorld `Mods` directory.
4. Enable the mod and restart the game if requested.

RimWorld automatically loads the appropriate assemblies for versions 1.6 and 1.7.

## Compatibility

The mod preserves vanilla growth tiers 1–8.

Compatibility with other mods that modify the same child growth mechanics is not guaranteed.

# 한국어 안내

**Steam 창작마당:**  
https://steamcommunity.com/sharedfiles/filedetails/?id=3827770524&l=koreana

Growth Tiers Plus는 RimWorld Biotech의 아동 성장 시스템에 **성장 티어 9와 10**을 추가하는 모드입니다.

기존 **바닐라 성장 티어 1~8은 변경하지 않습니다.**

**지원 버전:** RimWorld 1.6 / 1.7  
**필수 요구사항:** Biotech DLC, Harmony  
**세이브 호환:** 기존 세이브에 추가 가능  
**지원 언어:** 한국어, 영어

## 주요 기능

- 성장 티어 9와 10 추가
- 성장 티어 9·10 개별 활성화 및 비활성화
- 필요 성장 점수 설정 (기본값: 168 / 172)
- 열정 획득 최소·최대 개수 설정
- 열정 및 특성 선택지 개수 설정
- 기존 바닐라 성장 티어 1~8 유지

**참고:** 성장 티어 1~8은 이 모드에서 변경하거나 설정할 수 없습니다.

## 설치 방법

**Steam 창작마당 (권장)**

Steam 창작마당에서 구독한 후, 림월드 모드 목록에서 활성화하세요.
